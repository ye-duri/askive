# 연세스튜디오 iPad 앱

사진 인쇄 버튼 → 클라우드 접수 → 인쇄관리 페이지에서 매수 선택 → CP1500 출력 순서입니다. 아이패드의 Mac 연결과 QR 운영 코드 입력은 필요하지 않습니다.

## 현재 프로젝트 업데이트

1. Xcode에서 `ios/YonseiStudio.xcodeproj`를 엽니다.
2. 상단 실행 대상을 실제 `iPad (4)`로 선택하고 **⌘R** 또는 ▶를 누릅니다. 기존 Team 설정을 유지합니다.
3. iPad에서 업데이트된 앱을 실행합니다.
4. 카메라를 허용하고 촬영합니다. QR 저장은 코드 입력 없이 자동 연결됩니다.
5. 사진 촬영 후 사진 인쇄를 누릅니다. 인쇄관리 페이지에서 매수를 정하고 출력합니다.

웹 기능은 앱을 다시 열면 갱신됩니다. 기존에 설치된 앱에서 Mac 연결 메뉴 자체를 제거하려면 Xcode의 ▶로 업데이트 설치해야 합니다.

세부 운영·보관·오류 안내는 [Mac 인쇄 도우미 안내](../mac-print/README.md)를 참조하세요. Mac 도우미는 운영 중 계속 실행해야 합니다.

## 처음 설치할 때

Signing & Capabilities에서 Automatically manage signing과 본인의 Team을 선택합니다. 실제 iPad를 Xcode에 연결해 이 컴퓨터 신뢰를 허용하고, iPad 설정 → 개인정보 보호 및 보안 → 개발자 모드를 활성화합니다. 실행 후 개발자 신뢰 안내가 나오면 기기 설정에서 승인합니다.

## 코드 구성

- 웹 `dist/app.js`: 촬영·선택·합성·QR 생성과 클라우드 인쇄 접수를 처리합니다. 기본 필터는 원본입니다.
- `StudioWebView.swift`: 허용된 HTTPS 웹사이트와 카메라 권한만 처리합니다.
- `YonseiStudioApp.swift`: 카메라 설정 메뉴만 제공합니다.
- `Info.plist`: 카메라 사용 목적을 설정합니다. 로컬 네트워크·Bonjour 연결은 제거했습니다.

QR에 동의한 사진의 인쇄본에는 QR이 들어갑니다. QR 웹 앨범에 저장되는 완성본은 QR을 넣기 전 이미지입니다.
