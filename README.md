# ASKIVE

**ASK + ARCHIVE — 우리의 순간을 모으다.**

행사 현장에서 아이패드와 휴대폰으로 촬영하고, 원하는 사진을 골라 프레임에 담는 웹 포토부스입니다.

![ASKIVE 로고](branding/askive-logo.png)

## 사용 흐름

카메라 허용 → 컷 수·프레임·타이머 설정 → 10장 개별 촬영 → 원하는 사진 선택 → 프레임·필터 적용 → 저장·인쇄·공유 → 이용 종료

- 1·2·4·6컷 구성과 컷 수에 맞는 프레임 선택
- 내장·USB 카메라 선택, 연결 해제 후 촬영 사진 유지와 재연결
- 촬영 중 프레임 오버레이와 타이머 변경
- 원본·화사·선명 필터: 프레임을 제외한 사진에만 적용
- 투명 PNG/WebP 프레임 추가 및 Canvas 합성
- 운영체제 인쇄창과 파일 공유 기능 연동

## 설계

HTML/CSS/JavaScript와 브라우저 카메라 API, Canvas를 사용합니다. 촬영·선택·합성은 기기에서 처리하며 현재 화면은 사진을 서버에 업로드하지 않습니다. 프레임 파일과 슬롯 좌표를 분리하여 디자인을 추가할 수 있습니다.

Cloudflare Pages에는 `dist/`만 배포합니다. `server.mjs`는 로컬 실행용이며, 포함된 이전 MMS API는 기본 비활성화 상태로 Pages에서 실행되지 않습니다. 브라우저 공유는 자동 문자 발송과 다릅니다.

## 로컬 실행

Node.js 24 이상이 필요합니다. 외부 npm 의존성 설치는 없습니다.

```sh
npm start
```

http://localhost:4173 에 접속합니다. 다른 기기의 카메라 사용은 HTTPS 배포 주소에서 확인합니다.

## 검사

```sh
npm run check
npm test
```

테스트는 모의 카메라·DOM·문자 제공자를 사용합니다. 실제 문자 발송은 하지 않습니다. 실제 iPad의 카메라·공유창·SELPHY 출력 검증을 대신하지 않습니다.

## 저장소 구조

| 경로 | 역할 |
|---|---|
| `dist/` | 실제 배포할 웹앱 |
| `dist/frames.json` | 프레임 목록과 사진 슬롯 좌표 |
| `dist/frames/` | 프레임·로고·캐릭터 |
| `server.mjs` | 로컬 서버 및 비활성 이전 문자 API |
| `tests/` | 기능·서버 테스트 |
| `branding/` | 로고 제작 자료 |
| `docs/` | 프레임 제작 템플릿·운영·배포 가이드 |

## 현재 한계

실제 행사 기기에서 촬영부터 출력까지 확인해야 합니다. 프린터 연결과 인쇄 완료 감지는 웹앱이 수행하지 않습니다. Cloudflare Pages용 보안 헤더는 `dist/_headers`에 별도로 설정합니다. 개인정보 문의 연락처는 운영 전에 설정해야 합니다.
