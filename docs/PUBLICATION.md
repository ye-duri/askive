# 공개 범위

실제 `.env`, 인증 키와 토큰, 촬영 결과물은 공개 대상에 포함하지 않습니다. `.env.example`의 키·비밀번호 값은 비어 있고 테스트의 `test` 값은 모의 제공자 전용입니다.

모먼트 예시 프레임과 기존 프리뷰는 공개본에서 제외하고 기본 템플릿 기반 2×2 프레임으로 교체했습니다. ‘함께 찍기 · 2×2’ 프레임은 사용자가 실제 인물이 아닌 가상 인물 디자인이라고 확인하고 공개를 요청하여 포함했습니다. 다운로드 폴더의 원본은 변경하지 않았습니다.

사용자가 프로젝트용으로 제공한 양 캐릭터와 파생 디자인은 프로젝트 자산으로 포함합니다. 이를 제3자가 자유롭게 재사용할 수 있다는 라이선스를 부여한 것은 아닙니다. 글꼴은 동봉 OFL을 따릅니다.

향후 API 키가 필요한 기능은 서버 측 비밀 설정으로 구현해야 합니다. 프런트엔드 JavaScript나 dist에 넣은 값은 비공개 환경 변수에서 빌드했더라도 공개될 수 있습니다. 현재 정적 배포에는 API 키가 필요하지 않습니다.
