# 실행·운영 안내

## 로컬 실행
Node.js 24 이상에서:
```sh
cd askive
npm start
```
http://127.0.0.1:4173/ 를 엽니다. 외부 npm 의존성 설치는 없습니다. 검사 명령은 `npm run check`, `npm test`입니다. 테스트는 모의 카메라/문자 제공자를 사용하며 실제 문자를 보내지 않습니다.

## 다른 기기 / iPad
현재 localhost 주소는 서버가 실행 중인 컴퓨터에서만 접근하는 주소입니다. iPad에서 쓰려면 `dist/`의 정적 파일을 HTTPS 웹 호스팅에 올려 접속하세요. 사진 촬영·합성은 기기에서 처리됩니다. 카메라 사용에는 HTTPS와 브라우저 권한이 필요합니다.

Node 서버를 외부에 노출하는 경우 HTTPS 리버스 프록시와 PUBLIC_ORIGIN 설정이 필요합니다. `.env.example`은 빈 설정 예시입니다. 실제 키는 포함하지 않았습니다. 정적 배포에서 개인정보 문의 연락처를 바꾸려면 dist/index.html의 안내도 설정하세요. 현재 연락처는 미설정입니다.

## 행사 운영
최초 카메라 허용 → 컷 수/프레임/타이머 → 한 장씩 총 10장 촬영 → 원하는 사진 선택 → 프레임/필터 → 저장·인쇄·발송 → 이용 종료·사진 지우기.
촬영 도중 처음부터 다시 찍기와 카메라 전후면 전환은 제공하지 않습니다. 타이머는 촬영 사이에 조정할 수 있습니다.

## 사진 발송과 인쇄의 실제 범위
발송은 동의 후 기기의 파일 공유창을 열며 사용자가 메시지 앱과 수신자를 선택합니다. 웹앱이 번호로 문자를 직접 발송하거나 메시지 앱을 강제로 지정하지 않습니다. 사진/전화번호를 이 웹앱 서버에 업로드하지 않습니다. 메시지 지원 여부는 OS/브라우저에서 확인해야 합니다.
인쇄는 운영체제 인쇄창을 엽니다. CP1500 직접 연결/블루투스 출력/완료 감지 기능은 없습니다. 기기에서 프린터를 사용할 수 있게 먼저 설정하고 시험 인쇄하세요. 출력 용지와 배율, 잘림은 최종 인쇄창에서 확인합니다.

## 데이터 정리
이용 종료 버튼으로 앱이 참조하는 촬영 사진과 미리보기를 지웁니다. 이미 다운로드했거나 메시지로 전달한 사진은 별도로 남습니다. 서버 전송이 비활성화된 이전 문자 연동 코드는 소스에 포함되어 있지만 실제 운영 기능으로 연결된 상태가 아닙니다.

## 검증 범위
문법·모의 촬영 및 선택·필터·프레임·보안 테스트와 프레임 렌더링 확인을 수행했습니다. 실제 행사 iPad/SELPHY의 촬영·발송·인쇄는 현장 기기에서 최종 확인해야 합니다.
