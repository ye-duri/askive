# 2026-09-22 보안 조치

- resetSession()에서 촬영 Canvas, 결과/인쇄 이미지, 방문자 프레임과 blob URL을 정리합니다. 기본 등록 프레임은 유지합니다.
- 2분 비활동 경고, 30초 후 초기화. 촬영 중 유예하고 공유·인쇄는 최대 5분간 유예하며 pagehide에서 정리합니다. 실제 iPad의 공유·인쇄 이벤트는 현장 확인이 필요합니다.
- 업로드: 5개, 합계 30MB, 개별 10MB, 2,400만 화소. PNG/WebP 헤더를 디코딩 전에 검사하고 디코딩 후 치수를 대조합니다. 헤더 검사만으로 모든 이미지 디코더 공격을 방어한다고 보장하지 않습니다.
- 촬영 전 방문자 프레임 삭제 버튼을 제공합니다. 종료·업로드가 겹쳐도 이전 작업은 세션을 복구하지 못합니다.
- 사용하지 않는 SENS 서버 발송 API를 제거했습니다. unlock/send는 410이며 ENABLE_SENS_MMS=true도 활성화하지 못합니다. 기기의 navigator.share는 유지합니다.
- 로컬 정적 서버에서 심볼릭 링크 제공을 거부합니다.
- Node 24.21.0 이상 24.x가 필요합니다. .nvmrc/engines/시작 시 검사로 이전 버전 실행을 차단합니다. 시스템 Node는 자동 업데이트하지 않습니다.

## 실행
Node 버전 관리 도구를 사용하는 경우 nvm install && nvm use 후 npm start를 실행합니다. 다른 설치 방식은 Node 24.21.0 이상 24.x를 설치합니다. npm run check 및 npm test를 확인합니다.

## 남은 운영 설정
공개 운영 주체는 예두리, 문의처는 010-5602-5740으로 사용자 요청에 따라 설정했습니다. 정적 Pages는 dist/index.html의 policy-contact 기본 안내를 직접 수정해야 합니다. 로컬 서버는 PRIVACY_CONTACT도 지원합니다. 기기에 남는 다운로드·메시지·인쇄 사본은 별도 정리해야 합니다.

## 배포
이 변경만으로 공개 Pages 사이트가 바뀌지 않습니다. 코드 검토 후 main에 commit/push하고 배포 완료 후 실제 iPad 검증을 진행합니다.
