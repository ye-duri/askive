# 행사 프레임 노출 설정

2026년 10월 시월장 행사에서는 `dist/frames.json`의 스페셜 에디션 중 `siwol-market-four`(기존)와 `siwol-market-peach-four`(살구색)를 표시합니다. 각 디자인은 4컷과 6컷을 제공하며, 6컷 ID는 `siwol-market-six`, `siwol-market-peach-six`입니다. 모두 시월장 달력 테마를 사용합니다. 다른 스페셜 항목에는 `hidden: true`를 설정했습니다. 기본 프레임과 기존 이미지 파일은 유지합니다.

다음 행사에서 다시 표시하려면 해당 항목의 `hidden`을 삭제하거나 `false`로 바꾸고, 모드 선택 화면의 예시 이미지도 맞춰 변경합니다. 프레임 생성 스크립트로 목록을 재생성한 경우 행사 노출 설정을 확인합니다.

QR 동의가 있는 사진은 인쇄 API에서 QR 없는 완성본(8번)을 전달하고, QR 주소를 별도 메타데이터로 보냅니다. 웹 미리보기와 Mac 출력 PDF는 같은 레이아웃으로 용지 우측 하단 로고 옆에 QR 하나를 표시합니다. 이전 9번 인쇄용 이미지에 포함된 QR은 반복 사용하지 않습니다.

Mac 출력 도우미에도 새 레이아웃과 QR 라이브러리가 필요합니다. 배포용 설치 파일에 포함되어 있으며 기존 사진과 연결 설정은 설치 시 보존됩니다.

WANT · 4컷(`want-four`)도 표시합니다. `printTheme: want`는 버건디 달력, 원본 OCT 글씨 및 금색 WANT 로고를 사용하며 QR은 기존처럼 하단에 하나만 배치합니다. 시월장 네 종류의 행사 날짜는 2026.10.24(Sat)입니다.
