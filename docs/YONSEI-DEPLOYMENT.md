# 연세스튜디오 배포 및 QR 저장 설정

2026-09-26. 구현·로컬 시험 완료. 운영 배포 이력은 docs/DEPLOYMENT-2026-09-26.md를 참고하세요. 물리 인쇄 검증은 별도입니다.

## Cloudflare Pages + R2

1. 기존 계정의 R2에서 `yonsei-studio-photos` 버킷을 생성합니다. r2.dev 공개 URL과 공개 도메인은 **켜지 않습니다**. 계정에서 R2 사용을 위한 결제 등록이 필요할 수 있습니다. 계정의 요금 조건을 확인한 후 활성화하세요.
2. Pages 프로젝트 `askive`의 Git 배포는 저장소 루트를 사용하고 출력 폴더는 `dist`로 둡니다. 루트의 `functions/`, `lib/`, `wrangler.toml`도 Git에 포함해야 합니다. dist ZIP 단독 업로드는 QR 서버를 배포하지 않습니다.
3. `wrangler.toml`의 `PHOTOS` 바인딩이 위 버킷을 가리키는지 확인합니다. 현재 Preview에는 R2 바인딩을 주지 않고 QR 저장을 비활성화합니다. Preview QR 시험이 필요하면 운영용과 분리한 별도 버킷을 사용하세요.
4. Pages 프로젝트의 Secrets에 `KIOSK_SECRET`을 설정합니다. 최소 32자, 권장 32바이트 이상의 무작위 값입니다. 서버 환경에만 저장하고 Git·브라우저 JS·공지 QR에는 넣지 않습니다.
5. 동일 버킷에 연결된 만료 삭제 Worker를 배포합니다:

```sh
npx wrangler deploy --config cleanup/wrangler.toml
```

6. Worker에서 `*/10 * * * *` Cron이 활성화되고 실행이 성공하는지 확인합니다. R2 수명주기 규칙으로 생성 후 1일 삭제도 보조 설정할 수 있지만, 이 규칙만으로 정확한 24시간 접근 차단을 대신하지 않습니다.
7. 아래 검증이 끝난 뒤 `wrangler.toml`의 production 환경 변수 `CLEANUP_ENABLED="1"`로 배포합니다. 이것은 운영자가 삭제 작업을 확인했다는 표시이며, 코드가 Worker 배포 상태를 자동 검증한다는 뜻은 아닙니다.
8. 행사 iPad의 최초 카메라 화면에서 운영 코드를 입력합니다. 서버가 HttpOnly·SameSite 쿠키를 발급합니다. 유효 기간은 24시간이며, 운영 코드가 공개 이용자에게 노출되지 않도록 관리하세요.

### 삭제 기준

- 생성 시각 + 24시간부터 메타데이터와 모든 사진 조회를 차단합니다.
- 조회 시 만료를 발견하면 즉시 삭제합니다.
- 조회되지 않은 앨범은 정기 작업으로 최대 10분 후 삭제합니다(Worker 정상 가동 전제).
- 업로드가 중단된 앨범도 같은 만료 시각을 적용합니다.
- QR 링크가 유출되면 24시간 동안 타인이 열람할 수 있습니다. 삭제 버튼으로 폐기하세요.
- 직접 다운로드한 사본은 서버에서 회수하지 못합니다.

### 배포 전·후 확인

- `/api/gallery/config` 응답이 JSON이고 `configured:true`인지 확인합니다.
- 잘못된 운영 코드와 미인증 업로드가 거부되는지 확인합니다.
- 가짜 사진으로 QR을 생성하고 다른 휴대폰에서 8장+완성본을 열어봅니다.
- 만료 시각을 넘긴 시험 앨범의 접근 차단과 실제 객체 삭제를 확인합니다.
- 자동 삭제 Worker의 실패 알림·R2 용량을 운영 중 확인합니다.
- R2 설정·secret 없이 촬영하는 경우 QR 선택이 비활성화되고 저장·인쇄는 정상인지 확인합니다.

## CP1500 인쇄

웹 출력은 여백 0의 사진 전용 페이지이며, 실제 인쇄 페이지 전체를 차지하도록 수정했습니다. 이전처럼 앱이 고정한 작은 mm 영역만 A4 한구석에 찍히는 동작을 피합니다.

1. iPad와 CP1500을 같은 Wi-Fi에 연결합니다.
2. 웹의 인쇄 → 시스템 창에서 CP1500을 먼저 선택합니다.
3. 프린터의 실제 엽서 용지와 세로 방향을 선택하고 머리글·바닥글을 끕니다. 사진에 나온 '프린터 없음 / A4 / 타블로이드' 상태는 최종 출력 설정이 아닙니다.
4. 기본은 용지 채우기입니다. QR이 있는 결과는 코드 잘림을 막기 위해 전체 표시를 사용하며, 비율이 다르면 얇은 여백이 남을 수 있습니다. 세로 스트립과 가로 프레임도 비율을 보존합니다.
5. 실제 용지 테두리·확대 잘림은 Safari 및 프린터 설정에 따라 달라지므로 행사 전 시험 출력하세요. JS가 AirPrint 프린터나 용지를 강제 선택하지는 않습니다.

## 운영 설정 재연결

참가자용 베이직/특별에디션 화면에는 연결 점검 버튼이 없습니다. 운영 코드가 만료되거나 카메라를 바꿔야 하면 `/?setup=1`로 접속해 최초 설정 화면을 엽니다. 운영 코드 인증 후 다음을 누르면 일반 화면으로 돌아갑니다.

QR 동의는 이용자마다 초기화됩니다. 미동의 시 앨범 생성·사진 업로드를 하지 않으며, 서버도 명시적 동의 값 없이 앨범 생성 요청을 받으면 거부합니다.
