# Sheep special collection

12 layouts: farewell, club, friends, garden; each 4-cut 2x2, 6-cut 2x3 and landscape 4-cut 2x2. No single-column strips. Portrait 1200x1776 and landscape 1776x1200, SELPHY P 100x148mm. Right footer clear for existing QR.

Assets: branding/special/sheep-friends.png and sheep-farewell.png. Created with built-in image_gen using the user-provided sheep sheet as reference.
Prompt direction: flat hand-drawn Korean stationery sheep, scalloped opaque white wool, peach oval faces, thin dark outlines, restrained college clothes, transparent background; friends trio with green varsity/cream cardigan/blue cap, farewell duo in olive uniform saluting and cream cardigan waving with clover; no weapons, no badge, no frame, no text.

Native SVG borders and transparent masks are generated by scripts/build-special-collection.py, preserving precise slots; illustrations are embedded to keep canvas exports self-contained.
