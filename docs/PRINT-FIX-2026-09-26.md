# 인쇄 수정 — 2026-09-26

- 최종 사진 화면에서 window.print()를 동기 호출한다. 자체 인쇄 모달과 용지/잘림 설정은 제거했다.
- 완성본 생성 시 100×148mm, 300dpi JPG를 기기에서 미리 준비한다. 추가 서버 전송 없음.
- print.css를 마지막에 로드하여 화면용 fixed/100% 배치를 물리 단위의 정적 1페이지 배치로 덮어쓴다. @page 여백은 0.
- 전체 프레임 비율과 QR을 보존한다. 원본 3:4와 용지 비율이 다르므로 위아래 흰 영역은 의도된 것이며 무여백 확대를 위해 프레임을 자르지 않는다.
- 파일 공유 지원 기기에는 사진 파일로 인쇄 버튼을 제공한다. 웹페이지 날짜/URL을 피하려면 공유 메뉴의 프린트를 사용한다. 자동 프린트 선택이나 완료 확인은 제공하지 않는다.

## 검증
Chrome 자동 테스트: 버튼 클릭 1회 → print 호출 1회, 자체 dialog 없음. 다섯 촬영 흐름, QR 앨범, 카메라 복구/파일 공유 통과. PDF는 1페이지, 약 100×148mm, 머리글/바닥글 활성화 상태에서도 추출 텍스트 없음. 렌더링에서 전체 프레임과 QR 확인.

## 한계
실물 iPad Safari/AirPrint 및 CP1500 출력은 여기서 수행하지 못했다. 시스템에서 프린터와 엽서 용지를 선택해야 한다. A4 선택을 웹이 강제로 변경할 수 없다. Safari 버전에 따라 @page 규칙이나 머리글/바닥글 적용이 다를 수 있으므로 모든 iPad에서 날짜 제거를 보장하지 않는다. 그런 경우 최종 화면의 사진 파일로 인쇄를 사용한다.
