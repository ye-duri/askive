# ASKIVE 프레임 제작 가이드 — 최종 B안 기준

## 1. 파일 선택
- `../dist/frames/`의 서비스 SVG 15종: 최종 로고와 소제목이 적용된 실제 서비스 프레임입니다.
- `templates/upload-Ncut.svg` 및 PNG: 웹의 ‘내 프레임 추가’에 맞춘 기본 투명 템플릿입니다.
- `templates/guide-Ncut.svg`: 사진 영역의 번호·좌표를 확인하는 가이드입니다. 가이드 파일 자체를 촬영 프레임으로 업로드하지 마세요.
- `frame-layouts.json`: 서비스 프레임 각각의 정확한 픽셀 좌표 `[x, y, width, height]`입니다. 원점은 왼쪽 위입니다.

## 2. 기본 제작 규격
기본 캔버스는 1080 × 1440px, RGB/sRGB입니다. 투명 PNG 또는 WebP로 내보냅니다. 흰색을 칠한 사진 구멍은 투명이 아니며 카메라를 가립니다. 사진 영역을 실제 알파 투명으로 비워 주세요.

| 구성 | 캔버스 | 권장 출발 파일 |
|---|---|---|
| 1컷 | 1080 × 1440 | club-single.svg |
| 2컷 | 1080 × 1440 | club-duo.svg |
| 4컷 2×2 | 1080 × 1440 | club-grid.svg |
| 4컷 세로 | 600 × 1800 | club-strip.svg |
| 4컷 가로 | 1440 × 1080 | club-wide.svg |
| 6컷 2×3 | 1080 × 1440 | club-six.svg |

**서비스 등록 프레임과 간편 업로드 템플릿의 슬롯 위치는 다릅니다.** 레이아웃을 자유롭게 만들려면 아래 ‘기본 목록 등록’을 사용하세요. 업로드 화면은 슬롯 좌표를 받지 않고 컷 수에 따른 기본 격자를 사용합니다. 따라서 세로 4컷 파일을 간편 업로드하면 자동으로 세로 배치를 인식하지 않습니다.

## 3. 디자인 작업 순서
1. 최종 SVG 또는 해당 컷 수의 투명 템플릿을 디자인 도구에서 엽니다.
2. 사진 구멍 좌표와 캔버스 크기를 고정합니다.
3. 배경·장식·인물을 별도 레이어에 배치합니다. 투명 영역 위로 나온 장식과 인물은 촬영 사진 위에 합성됩니다.
4. 로고는 `../branding/askive-logo.svg`의 최종 B안입니다. 소제목은 ASK + ARCHIVE / 우리의 순간을 모으다입니다. `tagline-en.svg`, `tagline-ko.svg`는 글자가 벡터 경로라 글꼴 설치가 필요 없습니다.
5. 중요한 로고와 글자는 출력 가장자리에서 충분히 떨어뜨립니다. 실제 잘림은 인쇄 설정과 용지에 따라 달라지므로 시험 인쇄로 확인합니다.
6. 투명 PNG로 내보내고 카메라 미리보기, 사진 선택, 저장 결과, 실제 인쇄를 확인합니다.

## 4. ‘내 프레임 추가’로 행사 당일 사용
먼저 1/2/4/6컷을 선택한 다음 맞는 `upload-Ncut.png` 기반 파일을 추가합니다. PNG/WebP, 최대 10MB·24메가픽셀 제한입니다. 추가 프레임은 현재 페이지 세션에서만 유지됩니다. 새로고침하면 다시 추가해야 합니다. 로고나 사진 구멍을 자동으로 인식하지 않습니다.

## 5. 기본 목록에 영구 등록
파일명을 영문 소문자·숫자·하이픈으로 만들고 `dist/frames/my-frame.png`에 복사한 뒤 `dist/frames.json`에 추가합니다.

```json
{
  "id": "my-frame",
  "name": "우리 프레임 · 1컷",
  "src": "frames/my-frame.png",
  "count": 1,
  "slots": [[0.05555556, 0.04166667, 0.88888888, 0.77777777]]
}
```

`slots`는 픽셀 좌표가 아니라 `[x/전체너비, y/전체높이, 사진너비/전체너비, 사진높이/전체높이]`입니다. 배열 순서대로 선택 사진이 들어갑니다. `count`와 슬롯 개수는 일치해야 하고 모든 슬롯은 캔버스 안에 있어야 합니다. 위 예시는 1080×1440에서 x60,y60,w960,h1120입니다. 범위 계산에는 충분한 소수 자릿수를 사용하세요.

등록 SVG는 자체 완결 파일이어야 합니다. 외부 이미지·폰트 URL을 참조하지 마세요. 두 인물/예시 SVG는 원본 PNG가 내장되어 있으며, 도형과 로고는 편집할 수 있지만 PNG 내부 인물 자체는 벡터가 아닙니다.

## 6. 앱의 합성 규칙
캔버스 종횡비 1:4~4:1, 출력 긴 변은 최대 2400px입니다. 카메라는 각 슬롯을 채우도록 잘리므로 중요한 얼굴은 중앙에 배치하세요. 필터는 촬영 사진에만 적용되며 프레임은 원래 색을 유지합니다. 10장 촬영 후 1/2/4/6장을 순서대로 고릅니다.

## 7. 원본의 범위
SVG·PNG·소스 코드가 실제 제작 원본입니다. PSD/AI/Figma 문서는 별도로 제작되지 않았습니다. 이 전달본에는 최종 B안과 현재 프레임만 포함합니다. 사용자 사진과 비밀키는 포함하지 않습니다.
