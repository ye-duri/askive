# 연세스튜디오 — SELPHY P 프레임 가이드

새 템플릿: docs/templates/selphy-p/. 이전 템플릿은 참고용으로 보존하며 새 제작에는 사용하지 않습니다.
전체 작업 크기 1200×1776px, RGB/sRGB, 투명 PNG. 절취 후 실제 크기 100×148mm (약 305ppi). 용지는 절취 전 100×177mm이며, 출력 후 위아래 탭을 절취선에 따라 손으로 떼어냅니다. 탭은 디자인에 포함하지 않습니다.

2컷: 1열2행, 사진 1104×648px. 시작점 (48,48), (48,720).
4컷: 2열2행, 사진 540×648px. X=48,612 / Y=48,720.
6컷: 2열3행, 사진 540×424px. X=48,612 / Y=48,496,944.

사진 구멍은 알파 투명으로 만듭니다. 흰색으로 채우지 않습니다. Illustrator에서 upload-Ncut.svg를 열어 디자인한 뒤 아트보드를 사용해 1× PNG로 내보내고 픽셀 크기를 확인합니다. 이미 픽셀 크기를 정했으므로 300ppi 내보내기로 재확대하지 마세요. 가이드 이미지는 업로드용이 아닙니다.

QR은 앱이 추가합니다. 우측 하단 X992,Y1568,160×160px에는 배경만 배치합니다. 글자·인물·로고는 가장자리에서 36px 이상 떨어뜨립니다. 무테 인쇄의 실제 잘림은 프린터에서 시험 확인합니다.

현재 기본 제공 프레임 10종과 샘플은 모두 1200×1776px입니다. 함께찍기는 자체 좌표가 있으므로 docs/frame-layouts.json을 사용합니다. 간편 업로드는 위 표준 좌표를 사용하며 투명 구멍을 자동 인식하지 않습니다.

8장을 촬영한 뒤 2/4/6장을 고릅니다. 같은 사진을 여러 번 쓸 수 있습니다. 필터는 사진에만 적용됩니다.
