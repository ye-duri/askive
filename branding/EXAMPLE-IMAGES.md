# 선택 화면 예시 이미지

실제 참가자 사진이 아닌, 내장 이미지 생성 도구로 만든 가상 성인 인물 예시입니다.

- `dist/frames/example-basic.png`: 2×2 세이지 그린 포토부스, 가상의 한국인 성인 친구 두 명, 네 가지 포즈, 아이보리 배경, 텍스트 없음.
- `dist/frames/example-special.png`: 2×2 네이비 함께찍기 포토부스, 오른쪽 가상 성인 남성 게스트와 왼쪽 가상 성인 여성, 하트·브이·손인사 포즈, 텍스트 없음.
- 두 이미지는 기능 설명용 예시이며 제공 프레임의 실제 인물과 동일함을 뜻하지 않습니다.
- 각 카드에 '예시 이미지'를 표시합니다.
