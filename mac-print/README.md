# 연세스튜디오 Mac 인쇄 도우미

## 실행과 연결

1. Mac에서 `mac-print/Start.command`를 더블 클릭합니다. 실행 터미널을 유지합니다.
2. 자동으로 열리는 `http://127.0.0.1:4178`에서 프린터에 Canon SELPHY CP1500을 선택합니다.
3. 업데이트한 iPad 앱의 **운영 설정 → Mac 연결**에서 검색된 Mac을 선택합니다. 로컬 네트워크 접근 요청은 허용합니다.
4. Mac 관리 화면의 **iPad 자동 연결 승인**에서 iPad에 표시된 확인 숫자와 같은지 비교하고 **연결 승인**을 누릅니다. 요청은 2분 후 만료됩니다. 연결 정보는 iPad 키체인에 저장되어 다음부터 재사용됩니다. 자동 검색이 어려운 환경에서는 기존 연결 코드 입력도 사용할 수 있습니다.
5. iPad의 **사진 인쇄**를 누르면 이 Mac 화면에 사진이 들어옵니다. 매니저가 출력 매수(1~10장)를 정하고 **인쇄**를 누릅니다.

Mac과 iPad는 서로 통신할 수 있는 같은 Wi-Fi에 있어야 합니다. CP1500도 현재처럼 Mac에서 인쇄 가능한 상태를 유지합니다. iPad와 Mac 사이에 운영용 케이블은 필요하지 않습니다. Xcode로 앱을 업데이트하는 연결은 별도입니다.

## 동작과 보관

- 사진은 Mac에 수신될 때 자동 출력되지 않습니다. 운영자가 매수를 정한 뒤에만 인쇄합니다.
- 인쇄는 macOS의 등록된 프린터에 P 용지 무테(`Postcard.Fullbleed`), 100×148mm(가로 사진은 148×100mm) 인쇄용 PDF에 기본 배율 94%로 직접 중앙 배치합니다. 원본 JPEG는 바꾸지 않습니다. Mac 화면에서 85~100% 범위로 조절하며 다음 인쇄에도 브라우저에 저장한 배율을 사용합니다. 기존 인쇄 완료 작업에는 소급 적용하지 않습니다. 실제 가장자리와 방향은 첫 출력으로 확인하세요.
- iPad의 전송 완료는 Mac 수신 완료입니다. Mac의 인쇄 대기열 전송 완료도 용지 배출 완료를 의미하지 않습니다.
- 같은 JPEG를 다시 전송해도 중복 접수하지 않습니다. 완료 사진은 매수를 정해 **다시 인쇄**할 수 있습니다. 상단 배율이 새 요청에 적용됩니다. 인쇄 결과가 불확실하면 인쇄 센터 확인 후 재요청하도록 안내합니다. 전송 중 및 오래된 화면의 중복 요청은 차단합니다.
- 수신 파일은 `~/Library/Application Support/YonseiStudioPrint`에 보관합니다. 도우미가 실행 중일 때 수신 24시간 후 삭제하며, 종료 중 만료된 파일은 다음 실행 시 삭제합니다. 화면에서도 개별 삭제할 수 있습니다. 이미 프린터로 보낸 작업은 파일 삭제로 취소되지 않습니다.
- 도우미를 재시작해도 대기 사진과 연결 키를 유지합니다. 브라우저 창을 닫아도 도우미는 동작합니다. 종료는 실행 터미널에서 Control+C입니다.
- 실행 중 `caffeinate`로 유휴 잠자기를 방지합니다. Mac 덮개를 닫거나 수동으로 잠자기에 들어가면 연결이 끊길 수 있습니다.

## 연결 보안

연결 코드는 사진 전송 권한을 가진 비밀 키입니다. 공개하거나 QR 앨범에 넣지 마세요. iPad에는 Keychain에 저장합니다. 관리 화면과 매수 변경·인쇄는 Mac 내부에서만 허용합니다. 사진 전송은 로컬 HTTP이므로 암호화 통신은 아닙니다. 신뢰하는 행사 전용 네트워크에서 사용하고 외부 포트 개방은 하지 마세요.

## 문제 확인

- 연결 확인 실패: 실행 터미널 유지, 같은 Wi-Fi, iPad 로컬 네트워크 권한, Mac 방화벽의 Node 수신 허용을 확인합니다. 게스트 Wi-Fi의 기기 간 통신 차단도 확인합니다.
- 프린터가 없음: macOS 프린터 및 스캐너에 CP1500을 추가하고 미리보기에서 테스트합니다.
- 인쇄 확인 필요: macOS 인쇄 센터에서 실제 대기열을 확인합니다. 같은 작업을 무작정 다시 보내지 마세요.

## 개발 검증

Node.js 24에서 `node tests/mac-print.mjs`를 실행합니다. `tests/mac-print-ui.mjs`는 Playwright와 Chrome이 필요합니다. 두 테스트는 인쇄 명령을 가짜 함수로 대체하므로 용지를 출력하지 않습니다.

## 클라우드 사진 수신

인쇄 도우미를 실행한 뒤 로컬 인쇄관리 페이지의 `클라우드 인쇄 연결`에 행사 운영 코드를 입력합니다. 아이패드와 같은 Wi-Fi일 필요는 없으며 인터넷 연결은 필요합니다. 각 노트북에 운영 코드를 한 번 입력하면 이후 자동으로 연결됩니다. 도우미는 5초 간격으로 새 인쇄 요청을 확인하며, 사진을 받은 뒤 기존 매수·회전·배율 설정으로 수동 인쇄합니다.

완성 사진은 QR 선택과 관계없이 24시간 저장됩니다. QR을 선택한 경우에만 촬영 원본 8장을 추가 저장하고 공개 앨범을 제공합니다. 인쇄 버튼을 누르기 전 저장 사진은 인쇄 대기열에 올라가지 않습니다. 여러 노트북이 동시에 연결된 경우 먼저 사진을 접수한 노트북에 배정되므로 운영 중 사용할 인쇄 도우미만 연결하세요. 인터넷 전송 실패 시 도우미가 재시도하고, 앱은 접수 확인 후에만 초기화됩니다.

## 로그인형 웹 인쇄관리 페이지

배포 주소: https://askive.pages.dev/print/
행사 운영 코드로 로그인하면 클라우드의 출력용 완성 사진만 표시됩니다. 이 주소를 다른 노트북에 공유해 사용할 수 있으며, 노트북 등록과 인쇄 도우미는 필요하지 않습니다. 각 노트북의 운영체제에 CP1500을 등록한 뒤, 사진별 매수·회전·배율을 조절하고 사진 인쇄를 누릅니다. 브라우저 인쇄창에서 CP1500, Postcard/P 용지, 여백 없음, 100% 배율, 매수 1을 선택합니다. 페이지에서 지정한 매수만큼 인쇄 페이지를 생성하므로 인쇄창에서 매수를 다시 늘리지 않습니다. 실제 용지가 나온 뒤 출력 완료를 눌러 목록의 상태를 갱신합니다. 인쇄창을 취소했으면 대기로 돌리기를 선택합니다.
